# 初回相談ヒアリングシート生成ツール

## ツール概要

小規模事業者や個人事業主への初回相談前に、聞くべき質問、確認事項、次回アクションを整理するための静的Webツールです。

このツールは、情報を大量に集めるためのものではありません。初回相談を始める前に、相談内容を短く整理する補助ツールです。

## 対象ユーザー

- 小規模事業者や個人事業主の相談を受ける人
- 初回相談前に質問項目を整理したい人
- AI活用、LP・Web制作、SNS発信、業務整理などの相談を受ける人

## できること

- 相談内容を入力して、初回相談用のヒアリングシートを作成できます。
- 生成結果を「質問リスト」「確認事項」「次回アクション」に分けて表示します。
- 医療、法律、税務、労務、投資、許認可などに関わる可能性がある場合は、「専門家に確認する項目」を表示します。
- 生成結果をコピーできます。

## 入力項目

- 相談テーマ
- 事業・活動の概要
- 今困っていること
- 希望する支援内容
- 相談の種類

## 出力される内容

- 質問リスト
- 確認事項
- 次回アクション
- 必要に応じた「専門家に確認する項目」

出力は、初回相談でそのまま使いやすい短い箇条書きを中心にしています。

## 使い方

1. `index.html` をブラウザで開きます。
2. 入力欄に相談内容を入力します。
3. 相談の種類を選びます。
4. 「ヒアリングシートを作成する」ボタンを押します。
5. 画面下の生成結果を確認します。
6. 必要に応じて「生成結果をコピーする」ボタンでコピーします。

## 注意点

- このツールは初回相談前のヒアリング項目を整理するための補助ツールです。
- 専門的な判断や助言を行うものではありません。
- 医療、法律、税務、労務、投資、許認可などに関わる内容は、必ず専門家に確認してください。
- 氏名、住所、電話番号、メールアドレス、口座情報、契約情報、詳細な売上、顧客名などの個人情報や機密情報は、必要以上に入力しないでください。
- 入力内容や生成結果をコピー・共有する場合は、個人情報や秘密情報が含まれていないか確認してください。
- このツールは静的Webページとして動作し、外部サーバーへの保存や送信は行わない設計です。

## 専門判断について

このツールは、相談内容への断定的な答えを出す目的では使いません。

相談前に「確認すること」「聞いてみること」「整理すること」をまとめるために使います。専門判断が必要な内容は、専門家に確認する項目として扱ってください。

## 履歴保存をしない理由

初回相談の内容には、個人情報や機密情報が含まれる可能性があります。

そのため、初回MVPでは履歴保存機能を入れていません。入力内容や生成結果はブラウザ内に保存されません。

将来、履歴保存機能を追加する場合は、ブラウザ内保存であること、別端末や別ブラウザには同期されないこと、同じ端末を使う人に見られる可能性があること、履歴削除機能を用意することを明記します。

## ファイル構成

- `index.html`: 画面構造
- `style.css`: 見た目
- `script.js`: ヒアリングシート生成とコピー機能
- `README.md`: 概要、使い方、注意点

## 公開前の動作確認手順

1. `index.html` をブラウザで開きます。
2. サンプル入力を入れて、「ヒアリングシートを作成する」ボタンを押します。
3. 結果が「質問リスト」「確認事項」「次回アクション」に分かれて表示されることを確認します。
4. 専門判断に関わる言葉を入力した場合、「専門家に確認する項目」が表示されることを確認します。
5. 「生成結果をコピーする」ボタンを押し、コピーできることを確認します。
6. スマホ幅でも入力欄と結果欄が見やすいことを確認します。
7. 未完成リンクや仮文言が残っていないことを確認します。

## 更新・公開手順

このプロジェクトは、GitHubとNetlifyを連携して公開できます。

### 基本の流れ

1. ローカル環境でファイルを修正する
2. ブラウザで `index.html` を開き、表示と動作を確認する
3. Codexで変更内容を確認し、コミットする
4. ユーザーがPowerShellでGitHubへpushする
5. Netlifyの自動デプロイ完了後、公開URLで表示を確認する

### Netlify設定

- Branch: `main`
- Build command: 空欄
- Publish directory: `.`

### コミット例

```bash
git add .
git commit -m "chore: GitHub連携デプロイ用の運用ルールを追加"
```

## サンプル入力

相談テーマ：
AIを仕事に使いたい

事業・活動の概要：
地域の小規模店舗を運営している

今困っていること：
ChatGPTを使ってみたいが、自分の仕事で何に使えるのか分からない。SNS投稿や資料作成に使える気はするが、最初の一歩が決められない。

希望する支援内容：
仕事に合わせたAI活用方法を整理し、すぐ試せる使い方を知りたい

相談の種類：
AI活用相談
